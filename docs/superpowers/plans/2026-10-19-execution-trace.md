# Execution Trace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While a tool runs, the page shows the sandbox's current line as a vim cursor line and a progress bar that only advances; the sandbox can emit nothing but 4-byte line numbers through a FIFO in its run directory.

**Architecture:** The sandbox runner gains `--trace <fifo>` and a `sys.monitoring` LINE hook limited to the tool file, writing little-endian `uint32` records non-blocking. The app creates the FIFO before `podman run`, reads it with an asyncio reader that validates and rate-limits records, and publishes them to a per-run `TraceChannel` keyed by a random token the page generated; `GET /trace/{token}` streams them as server-sent events. The page moves the cursor per event and sets the bar to `max(line)/lines`.

**Tech Stack:** Python 3.12 `sys.monitoring` (sandbox), `os.mkfifo` + `asyncio` `add_reader` (app), Starlette `StreamingResponse` SSE, vanilla JS `EventSource`, pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-10-19-execution-trace-design.md`

## Global Constraints

- Record format: exactly 4 bytes, unsigned little-endian line number (`struct.pack("<I", line)`); the app drops records outside `1 ≤ line ≤ <lines in tool file>` and discards partial trailing bytes.
- Rate limit: at most 60 events/s forwarded (latest line per tick wins); browser side one cursor move per animation frame.
- The trace must never change a run's outcome or raise into `PodmanRunner.run`; sandbox-side errors (no reader, full pipe) are swallowed.
- Token: 32 URL-safe characters generated by the page per load; channel registered only while a run is in flight, forgotten 60 s after creation if never started; bounded queue of 1,000 events.
- Sandbox image change (`sandbox/` package) ships through CI; the app side ships through `deploy.sh`. Order: push sandbox + app together; the running app picks up the new sandbox image on its 10-minute refresh or at restart (`deploy.sh` restarts it).
- Tests: `cd server && python -m pytest -m "not integration"` green after every task; sandbox tests run with the sandbox package installed `--no-deps` into the dev venv: `cd sandbox && python -m pytest`.
- Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; push to `main` allowed.

## Review Focus

1. A tool that deletes or replaces `<run dir>/trace` (it owns the directory) must not break the run or the reader: reader sees EOF/`ENOENT`, logs, ends; run outcome unchanged. Test in Task 4 (`test_run_survives_missing_fifo`).
2. A tool that writes garbage (odd byte counts, huge numbers) to the FIFO must produce no events beyond validated lines and no exception. Test in Task 3 (`test_reader_drops_invalid_and_partial_records`).
3. Browser attaches late or never: events queue (bounded) and the channel still closes at run end; an SSE client that never connects must not keep the channel alive past 60 s. Tests in Task 5 (`test_channel_queue_is_bounded`, `test_unregistered_token_expires`).
4. Two runs from the same page (token reuse): a token is single-use; a second run with the same token gets its own fresh channel and the old stream ends. Test in Task 5 (`test_token_reuse_replaces_channel`).
5. Run rejected before the sandbox starts (busy / unavailable / 404): the channel is closed with `end` immediately so the EventSource does not hang. Test in Task 5 (`test_channel_closed_on_busy`).

**Files:**

**Interfaces:**
- Produces: `class LineTracer` with `__init__(self, tool_file: Path, fd: int)`, `start()` and `stop()`; while started, every LINE event in code objects whose `co_filename == str(tool_file)` writes `struct.pack("<I", line)` to `fd` with `os.write`, ignoring `BlockingIOError`, `BrokenPipeError` and `OSError`. Uses `sys.monitoring` tool id `sys.monitoring.PROFILER_ID` with `events.LINE`; the callback returns `sys.monitoring.DISABLE` for code objects from other files so they are never called again.
- Produces: `open_trace(path: str) -> int | None`: `os.open(path, os.O_WRONLY | os.O_NONBLOCK)`, returning `None` on any `OSError` (no reader, missing path).

```python
import os, struct, textwrap, importlib.util
from pathlib import Path
from sandbox.trace import LineTracer, open_trace

def run_tool(tmp_path, code, fd):
    tool = tmp_path / "t.py"; tool.write_text(textwrap.dedent(code))
    spec = importlib.util.spec_from_file_location("t", tool); mod = importlib.util.module_from_spec(spec)
    tracer = LineTracer(tool, fd); tracer.start()
    try:
        spec.loader.exec_module(mod); return mod.t()
    finally:
        tracer.stop()

def read_lines(r):
    data = os.read(r, 1 << 16)
    return [struct.unpack("<I", data[i:i+4])[0] for i in range(0, len(data) - len(data) % 4, 4)]

def test_lines_of_the_tool_file_are_written_in_order(tmp_path):
    r, w = os.pipe(); os.set_blocking(w, False)
    assert run_tool(tmp_path, """
        import json
        def t():
            x = 1
            for i in range(2):
                x += i
            return json.dumps(x)
    """, w) == "2"
    lines = read_lines(r)
    assert lines[:2] == [2, 3] or lines[:3] == [1, 2, 3]  # module body then def; the body lines follow
    assert [l for l in lines if l in (4, 5, 6)][:3] == [4, 5, 6] and lines.count(5) == 2 and lines[-1] == 7

def test_library_frames_are_not_traced(tmp_path):
    r, w = os.pipe(); os.set_blocking(w, False)
    run_tool(tmp_path, "import json\ndef t():\n    return json.dumps([1, 2])\n", w)
    assert max(read_lines(r)) <= 3  # json's own lines (hundreds) never appear

def test_full_pipe_drops_without_raising(tmp_path):
    r, w = os.pipe(); os.set_blocking(w, False)
    run_tool(tmp_path, "def t():\n    for i in range(100000):\n        pass\n    return 1\n", w)  # > 64 KB of records

def test_open_trace_without_reader_is_none(tmp_path):
    os.mkfifo(tmp_path / "trace")
    assert open_trace(str(tmp_path / "trace")) is None
    assert open_trace(str(tmp_path / "missing")) is None
```

### Task 3: App-side trace reader and channel registry

**Files:**
- Create: `server/src/app/utility/trace.py`
- Test: `server/tests/test_trace.py`

**Interfaces:**
- Produces: `class TraceChannel`: `queue: asyncio.Queue[int | None]` (maxsize 1000, `None` = end), `put(line: int)` (drops oldest when full), `close()`, `closed: bool`, `created: float`.
- Produces: `class TraceRegistry`: `register(token: str) -> TraceChannel` (closes and replaces an existing channel for the token), `get(token) -> TraceChannel | None`, `expire(now: float)` removing channels never closed after 60 s and closed ones after 10 s, `close(token)`.
- Produces: `async read_trace(fd: int, lines: int, on_line: Callable[[int], None], *, max_per_second: int = 60, clock=time.monotonic, sleep=asyncio.sleep) -> None`: reads via `loop.add_reader` until EOF or error; keeps the latest valid line per tick and calls `on_line` at most `max_per_second` times per second; never raises (logs and returns).

```python
import asyncio, os, struct
import pytest
from app.utility.trace import TraceChannel, TraceRegistry, read_trace

async def test_reader_forwards_valid_lines_in_order(tmp_path):
    r, w = os.pipe(); seen = []
    task = asyncio.create_task(read_trace(r, lines=10, on_line=seen.append, max_per_second=10_000))
    os.write(w, b"".join(struct.pack("<I", n) for n in (1, 2, 3))); os.close(w)
    await task
    assert seen == [1, 2, 3]

async def test_reader_drops_invalid_and_partial_records(tmp_path):
    r, w = os.pipe(); seen = []
    task = asyncio.create_task(read_trace(r, lines=10, on_line=seen.append, max_per_second=10_000))
    os.write(w, struct.pack("<I", 0) + struct.pack("<I", 11) + struct.pack("<I", 7) + b"\x01\x02"); os.close(w)
    await task
    assert seen == [7]

async def test_reader_rate_limits_to_latest_line_per_tick():
    r, w = os.pipe(); seen = []
    now = [0.0]
    async def sleep(s): now[0] += s
    task = asyncio.create_task(read_trace(r, lines=1000, on_line=seen.append, max_per_second=60, clock=lambda: now[0], sleep=sleep))
    os.write(w, b"".join(struct.pack("<I", n) for n in range(1, 601))); os.close(w)
    await task
    assert len(seen) <= 60 and seen[-1] == 600

async def test_reader_survives_writer_that_never_connects():
    r, w = os.pipe(); os.close(w)
    await read_trace(r, lines=5, on_line=lambda n: None)  # EOF immediately, returns

def test_channel_queue_is_bounded():
    ch = TraceChannel()
    for n in range(1, 1500): ch.put(n)
    assert ch.queue.qsize() == 1000 and ch.queue.get_nowait() == 500

def test_registry_replaces_and_expires():
    reg = TraceRegistry()
    a = reg.register("tok"); b = reg.register("tok")
    assert a.closed and reg.get("tok") is b
    reg.expire(now=b.created + 61)
    assert reg.get("tok") is None
```

### Task 4: PodmanRunner wires the FIFO

**Files:**
- Modify: `server/src/app/utility/podman_runner.py` (`command`, `run`, `_supervise`)

**Interfaces:**
- Produces: `run(tool, run_dir, on_line: Callable[[int], None] | None = None)`; `command(name, tool, run_dir, trace: Path | None = None)` appends `--trace <trace>` after `--workdir` when given.
- Behaviour: with `on_line`, before `podman run` the runner `os.mkfifo(run_dir / "trace")`, opens it `O_RDONLY | O_NONBLOCK`, starts `read_trace(fd, lines=<line count of tool>, on_line)` as a task, and after the container exits cancels/awaits it and closes the fd. Any `OSError` in FIFO setup is logged and the run proceeds without a trace. Line count = `tool.read_text().count("\n") + 1`.
